State Parameters

Two states. Every visual property lerps between them during the seal animation. Open = something needs to happen. Sealed = everything is safe.

Open
  • Warmth: 0.22 (cool, slightly mineral)
  • Stone glow: 0.02 (barely perceptible)
  • Stone radius: 30px (small, inert)
  • Spoke width: 1.8px / opacity: 0.18
  • Ring contract: 0.0 (loose, spaced)
  • Interior: cool sand-to-mineral gradient
  • Case highlight: 0.04 (flat lighting)
  • Shadow: blur 24, alpha 0.14 (soft lift)
  • Cool wash: 0.06 (slight blue tint)
  • Corner darkening: 0.07
  • Gap breaches: 0.06 (visible ring gaps)
  • Shimmer: active (slow drift in interior)
Sealed
  • Warmth: 0.90 (warm, golden)
  • Stone glow: 0.30 (organic bloom)
  • Stone radius: 40px (grown, alive)
  • Spoke width: 6.5px / opacity: 0.65
  • Ring contract: 1.0 (tight, locked)
  • Interior: warm honey-to-sand gradient
  • Case highlight: 0.22 (focused specular)
  • Shadow: blur 14, alpha 0.07 (settled)
  • Cool wash: 0.00 (eliminated)
  • Corner darkening: 0.00 (warmed away)
  • Gap breaches: 0.00 (rings sealed)
  • Shimmer: killed (perfect stillness)
The emotional axis. Openâ†’Sealed is not just a visual transition. It maps to the user's emotional state: "I haven't recorded yet" â†’ "My voice is preserved and safe." Every parameter serves this axis. The stone leads the transition â€” its warmth and glow change first, and the mechanism (rings, spokes) follows.

Integration Code

The vault is a pure Canvas 2D render. No DOM dependencies, no external libraries. One function call renders it at any seal progress.

How to use. Import the full render code from vault-phase5-final.html. The key functions are: drawFrame(ms, isOpen) for animation, or set the OPEN/SEALED params and lerp manually for static renders. The vault needs: (1) a 600Ã—600 canvas element, (2) the utility functions (seededRandom, PerlinNoise, mix, rgba), (3) the offscreen static layers (hammer, velvet, stone texture), and (4) the pre-computed stone outline and vein data.
Static Render
// Render vault at any seal progress (0 = open, 1 = sealed)
const canvas = document.getElementById('myVault');
const t = 0.0; // 0 = open, 1 = sealed, 0.5 = mid-transition

// Set up offscreen layers (once at init)
initStaticLayers();

// Draw at specific seal progress
drawFrame(0, t === 0); // ms=0 â†’ uses OPEN params
// For sealed: manually set all params to SEALED values
Animated Seal
const P1=150, P2=500, P3=150, SILENCE=600;
const TOTAL = P1 + P2 + P3; // 800ms

function triggerSeal() {
  let start = null;
  function tick(ts) {
    if (!start) start = ts;
    const ms = ts - start;
    drawFrame(Math.min(ms, TOTAL), false);
    if (ms < TOTAL + SILENCE)
      requestAnimationFrame(tick);
  }
  requestAnimationFrame(tick);
}
Metal Color Function
function mineralMetal(warmth, lightness) {
  const cool = [122,128,136]; // #7A8088
  const warm = [188,178,158]; // warm bronze target
  const base = mix(cool, warm, warmth * 0.6);
  const light = [235,228,218];
  const dark  = [85,88,94];
  return lightness >= 0.5
    ? mix(base, light, (lightness-0.5)*2)
    : mix(dark, base, lightness*2);
}
